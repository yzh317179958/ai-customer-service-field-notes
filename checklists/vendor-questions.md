# Questions to ask before buying an AI agent

For anyone evaluating an AI agent, a chatbot or an AI automation agency for customer service. A vendor who runs real work can answer all of these with a screen share.

## Show it working

- [ ] Show one system of yours running on real work today. What volume does it handle?
- [ ] Show one case from start to finish with the tool calls visible. A fluent answer with no lookups is a text generator with a new label.
- [ ] Which of your numbers are measured, and which are estimates?

## What it does alone

- [ ] Which actions does it take alone, and who set that list?
- [ ] What is it not allowed to promise, and how is that enforced?
- [ ] Who decides when money is involved?

## When things fail

- [ ] What does it say when a lookup fails?
- [ ] How do you find out it made a mistake?
- [ ] When it hands a case to a person, what does the person receive: the whole conversation, or the facts?

## Records and data

- [ ] Where is each action recorded? Which version is recorded when a person changes the AI's proposal?
- [ ] Where does my customer data sit, and which outside services see it?
- [ ] Which of our systems does it read, and can it change anything in them?

## Quality over time

- [ ] How will I see what my staff corrected each week?
- [ ] Do you test on my real past cases before launch?
- [ ] Who fixes it when my policy changes?

## Money and exit

- [ ] What do I pay for: seats, hours, usage, a project, or finished work?
- [ ] If I stop, what do I keep?

## Warning signs

- A demo on invented cases. Real cases have long threads, missing order numbers and three questions in one email.
- An accuracy figure with no method behind it.
- "Fully autonomous" for work that involves refunds.
- No plan for finding mistakes.
- Payment in full before anything has run on your work.
